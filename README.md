# نظام إدارة ومبيعات صالون tech (المرحلة الرابعة - Offline-First POS)

نظام متكامل وشامل لإدارة ومبيعات صالونات الحلاقة يتكون من:
1. **الخادم الخلفي (Backend API):** مبني باستخدام **NestJS + TypeScript** مع قاعدة بيانات **SQLite (WAL Mode)** تعمل خلف الـ API حصرياً.
2. **لوحة تحكم المالك (Admin Web):** واجهة ويب متجاوبة مبنية باستخدام **Next.js 14 + TypeScript Strict Mode** باللغة العربية والاتجاه **RTL**.
3. **تطبيق الكاشير المكتبي (Cashier Desktop):** تطبيق مخصص لـ Windows مبني باستخدام **Tauri 2 + Rust + React + TypeScript** وقاعدة بيانات محلية مشفرة عبر **SQLCipher**.

```text
               ┌───────────────────────────────┐
               │  تطبيق الكاشير (Tauri Desktop) │
               │   Rust Native + React POS     │
               │  قاعدة SQLCipher المحلية       │
               └───────────────────────────────┘
```

---

## 🔐 سياسات الدخول والفصل الصارم بين الأدوار (Role Separation)

1. **حساب المالك (Owner):**
   - يدخل فقط إلى لوحة الإدارة (`Admin Web`).
   - ممنوع من تسجيل الدخول إلى تطبيق الكاشير المكتبي.
   - هو الشخص الوحيد المخول بإنشاء وتعديل الأقسام والمجموعات والخدمات والمنتجات والحلاقين وحساب الكاشير.
2. **حساب الكاشير (Cashier):**
   - يدخل فقط إلى تطبيق الكاشير المكتبي (`Cashier Desktop`).
   - ممنوع من دخول لوحة الإدارة.
   - إذا تم إيقاف الحساب من لوحة الأدمن، يتم رفض الدخول فوراً برسالة آمنة.
   - يتم تسجيل توقيت آخر تسجيل دخول (`last_login_at`) في سجلات التدقيق.

## 🛡️ قاعدة البيانات المحلية المشفرة والعمل دون إنترنت (Offline-First)

- **تشفير SQLCipher:** تُخزن جميع بيانات الكتالوج المحلي، ومعلومات الجلسة، وقائمة الحلاقين محلياً داخل قاعدة بيانات مشفرة بمفتاح 256-bit مشتق ومخزن بأمان عبر نظام التشغيل.
- **تنزيل الكتالوج (Catalog Snapshot):**
  - عند تسجيل الدخول وتوفر الإنترنت، يتم تنزيل لقطة الكتالوج النشطة فقط (الأقسام والمجموعات والخدمات والمنتجات والحلاقين النشطين).
  - لا يتم تنزيل العناصر المؤرشفة أو السجلات المحذوفة أو أي بيانات مالية/حساسة.
- **العمل في حال انقطاع الإنترنت:**
  - يعمل تطبيق الكاشير بشكل طبيعي 100% بالاعتماد على آخر نسخة مشفرة تم تنزيلها.
  - لا تظهر أي رسائل مزعجة تقطع عمل الكاشير.
  - يوضح مؤشر اتصال صغير في الـ Header حالة الشبكة:
    - 🟢 **متصل بالخادم**
    - 🟠 **يعمل محلياً (غير متصل بالخادم)**
    - 🔴 **غير متصل (لا توجد بيانات محفوظة بعد)**
    - 🔄 **جاري التحديث التلقائي للكتالوج**
    - ⚠️ **تعذر التحديث التلقائي**
- **التحديث التلقائي في الخلفية:**
  - عند عودة اتصال الإنترنت أثناء تشغيل التطبيق، يتم فحص وتحديث الكتالوج في الخلفية تلقائياً دون مقاطعة الكاشير.

## 💻 متطلبات وطريقة التشغيل

### 1. المتطلبات:
* **Node.js** إصدار 18.18 أو أعلى.
* **Rust & Cargo** (في حال بناء تطبيق Tauri الثنائي).

### 2. تثبيت الحزم (Workspaces):
```bash
npm install
```

### 3. إعداد ملفات البيئة:
* **للخادم الخلفي (`apps/api/.env`):**
  ```env
  PORT=3001
  NODE_ENV=development
  DATABASE_FILE=./data/tech_server.sqlite
  JWT_SECRET=super-secret-key-change-this-in-production-random-secure-string-min-32-chars
  JWT_EXPIRES_IN=7d
  CORS_ORIGIN=http://localhost:3000
  ```

### 4. أوامر التشغيل:
```bash
# تشغيل الخادم الخلفي:
npm run dev:api

# تشغيل لوحة الإدارة (Admin Web):
npm run dev:web

# تشغيل واجهة الكاشير المكتبي (Desktop Frontend):
npm run dev:cashier
```

### 5. الفحص والاختبارات وبناء الإنتاج:
```bash
npm run test         # تشغيل كافة اختبارات الـ API (24 اختباراً آلياً)
npm run lint         # فحص TypeScript لكافة التطبيقات الثلاثة
npm run build        # بناء إنتاج كامل لـ API و Admin Web و Cashier Desktop
```
